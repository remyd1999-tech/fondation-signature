Comment installer votre signature

Après avoir copié votre signature, suivez les étapes correspondant à votre logiciel de messagerie.

Gmail (navigateur)
  1. Cliquez sur Copier la signature ci-dessus.
  2. Dans Gmail, ouvrez Paramètres (icône d’engrenage) → Voir tous les paramètres.
  3. Dans l’onglet Général, descendez jusqu’à la section Signature.
  4. Créez une nouvelle signature ou ouvrez une signature existante, puis collez (Ctrl+V ou ⌘+V).
  5. Cochez la case qui permet d’insérer la signature avant le texte cité dans les réponses et de supprimer la ligne « -- » qui précède.
  6. Enregistrez les modifications en bas de page. Si l’image ne s’affiche pas immédiatement, envoyez-vous un e-mail test : Gmail charge parfois les images au premier envoi.
Apple Mail (Mac)
  1. Cliquez sur Copier la signature ci-dessus.
  2. Ouvrez Mail → Réglages (ou Préférences) → onglet Signatures.
  3. Sélectionnez votre compte, créez une nouvelle signature, puis collez dans la zone d’édition.
  4. Décochez si nécessaire « Toujours utiliser ma police de message par défaut » afin de conserver la mise en forme.
  5. Associez la signature à votre compte. L’image s’affiche correctement tant que la page de cet outil reste accessible en ligne (GitHub Pages).
Outlook (Windows — application)
  1. Cliquez sur Copier la signature ci-dessus.
  2. Dans Outlook : Fichier → Options → Courrier → Signatures….
  3. Créez une nouvelle signature. Collez directement dans l’éditeur (Ctrl+V).
  4. Si la mise en forme semble incorrecte, collez d’abord dans Word, vérifiez l’aperçu, puis recopiez vers Outlook.
  5. Définissez cette signature comme signature par défaut pour les nouveaux messages et les réponses, puis validez avec OK.
Outlook (Mac) & Outlook sur le web
  1. Cliquez sur Copier la signature ci-dessus.
  2. Outlook Mac : Outlook → Réglages → Signatures → collez dans la signature.
  3. Outlook sur le web : Paramètres → Compte → Signatures → collez le contenu, puis enregistrez.
  4. Envoyez-vous un message test pour vérifier que le logo s’affiche bien.
Conseils utiles
  • Vous pouvez aussi cliquer sur Sélectionner l’aperçu, puis utiliser Ctrl+C / ⌘+C.
  • Le logo est hébergé avec cet outil : une fois publié sur GitHub Pages, l’image reste disponible pour tous vos destinataires.
  • En mode sombre, certains clients inversent les couleurs. Notre signature est conçue sur fond blanc pour limiter ces effets.
